알약 카운터 · Windows 독립 자동 출력

유팜데일리는 필요하지 않습니다.
1. ZIP 파일을 폴더에 모두 압축 해제합니다.
2. Start.cmd를 실행하고 이 PC의 라벨프린터를 선택합니다.
3. PC 웹 화면의 연결 상태가 '자동 출력 연결됨'이면 휴대폰으로 QR을 읽습니다.
4. 휴대폰에서 라벨을 전송합니다. PC에서 매번 인쇄 버튼을 누르지 않아도 됩니다.

Windows 10/11 64비트, 설치된 Windows 프린터 드라이버, 인터넷 연결이 필요합니다.
최초 실행 시 Python 공식 서버에서 검증된 전용 구성요소를 자동으로 받습니다.
프린터 드라이버의 용지를 장착된 롤에 맞춰 주세요. QL-550 / DK-22210은 폭 29mm 연속 용지입니다.
연결 프로그램 창을 열어 두세요. 브라우저를 닫아도 수신합니다.
연결은 생성 시점부터 8시간 후 만료됩니다. PC 웹 화면에서 새 파일과 QR을 만드세요.
오류 발생 시 실제 출력물을 확인한 뒤 R을 눌러 다음 요청 수신을 재개하세요.
실패하거나 결과가 불확실한 라벨을 자동으로 재출력하지 않습니다.
연결 파일에는 출력 권한이 들어 있습니다. 다른 사람에게 공유하지 마세요.
회사 보안 정책이 실행을 차단하면 관리자에게 확인하세요.
작은 용지는 내용을 자동 축소합니다. 모바일 미리보기에서 축소 비율과 내용을 확인하세요.
실제 프린터에서는 첫 라벨의 크기와 바코드, 출력 내용을 확인해 주세요.
