알약 카운터 · PC 직접 연결

1. ZIP을 PC의 일반 폴더에 모두 풀고 Start.cmd를 실행하세요.
2. Brother QL-550과 같은 공유기에 연결된 PC 주소를 선택하세요.
3. PC 연결 화면의 QR을 휴대폰으로 읽으세요.
4. 최초 1회 PC 인증서를 휴대폰에 등록하고 PC 화면의 인증서 지문과 대조하세요.
   삼성/Android: 설정에서 '인증서 설치' 검색 → CA 인증서 → 받은 파일 선택.
   iPhone: 프로파일 설치 → 일반 → 정보 → 인증서 신뢰 설정.
5. '카운터 열기' → 기존처럼 촬영/카운팅/소분/라벨 전송.

앱과 모델은 PC에서 받으며 라벨도 PC로 직접 전송합니다. Vercel 저장소를 사용하지 않습니다.
PC와 휴대폰은 같은 공유기를 사용해야 합니다. 게스트 Wi-Fi의 기기 격리 기능은 연결을 막을 수 있습니다.
PC 프로그램 창은 켜 두세요. QR 브라우저 창은 닫아도 수신됩니다. 종료: 프로그램 창에서 Ctrl+C.
연결 토큰은 시작/새 QR마다 바뀌고 8시간 후 만료됩니다. 새 QR을 읽으면 다시 연결할 수 있습니다.

연결되지 않을 때
- PC 주소/전원/같은 공유기 여부를 확인하세요. 공유기에서 PC 주소를 DHCP 예약하면 안정적입니다.
- Windows 개인 네트워크에서 이 프로그램을 허용하세요.
- 필요하면 Firewall.cmd를 관리자 권한으로 한 번 실행하세요.
  개인 네트워크의 같은 서브넷에서 TCP 8443/8444만 허용합니다.
- 인터넷 공유기의 포트 포워딩은 설정하지 마세요.
- 인증서 오류는 해당 PC 인증서 설치와 지문을 확인하세요. 다른 사이트의 오류를 무시하지 마세요.

QL-550 / DK-22210
기존 드라이버와 PrintDocument 출력 경로를 사용합니다. 용지는 29mm 연속입니다.
프린터 전송 성공은 실제 종이 출력 완료를 뜻하지 않습니다. 용지/출력물을 확인하세요.
오류/불확실한 출력은 자동 재인쇄하지 않습니다. PC 연결 화면에서 확인 후 재개하세요.
이전 클라우드 출력 프로그램은 종료하세요. 새 방식에서 이전 대기 라벨은 자동으로 재출력하지 않습니다.

유팜데일리에 내장하려면 CODEX_HANDOFF.md를 해당 개발창에 전달하세요.
이 ZIP의 독립 출력 프로그램은 유팜데일리 소스 수정 없이 사용할 수 있습니다.
인증서 개인키/저널은 사용자 LocalAppData/PillCounterDirect/state에 보관합니다.
더 이상 사용하지 않을 때 휴대폰에 등록한 PC 인증서를 삭제하세요.
